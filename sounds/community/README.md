# Community sounds

Sounds contributed by people who use this. Anything here is fair game:

```sh
buzzer set done <filename>
```

`buzzer sounds` lists everything available on your machine, including this
directory.

## Layout

One flat directory, one file per sound, plus a line in the table below.

```
sounds/community/
├── README.md          <- you are here; the table lives at the bottom
├── kettle.wav
└── typewriter-ding.wav
```

Name files after what they sound like, not after the event you happen to use
them for (`kettle.wav`, not `done.wav`). People use them for different events.

## Adding one

Read [CONTRIBUTING.md](../../CONTRIBUTING.md) first — the licensing bar is the
part that gets pull requests turned away, and it is not negotiable. In short:
under 2 seconds, normalised, WAV or MP3, and either your own work or something
you can point at a licence for.
